# AmneziaWG 3.1 روی روترهای OpenWrt

**VPN کل خانه با AmneziaWG 3.1 روی روتر OpenWrt، داخل کرنل، با split tunnel بدون سربار (سایت‌های ایرانی مستقیم) و رفع مشکل DNS. پکیج آماده برای Google WiFi، اسکریپت بیلد برای هر روتری.**

[English](README.md)

همه‌ی دستگاه‌های وای‌فای و LAN خانه (گوشی، لپ‌تاپ، ایکس‌باکس و پلی‌استیشن، تلویزیون) بدون نصب هیچ اپی از تونل [AmneziaWG](https://github.com/amnezia-vpn) رد می‌شوند. AmneziaWG همان WireGuard است با مبهم‌سازی ترافیک، برای عبور از DPI.

## چرا این پروژه

- **پکیج AWG 3.1 برای OpenWrt وجود نداشت.** پروتکل 3.1 ماژول کرنل هم‌نسخه لازم دارد. سرور اپ Amnezia با 3.1 کار می‌کند و بیلدهای قدیمی روتر نه.
- **بازی و تماس روی اینترنت فیلترشده خراب است.** روی یک خط خانگی در ایران حدود ۳۰ تا ۳۵ درصد packet loss روی UDP تا سرور بازی (AWS فرانکفورت) اندازه گرفتیم، و سرور لاگین بازی هم با SNI بسته بود. از داخل این تونل: **صفر درصد loss**، لاگین کار می‌کند، پینگ حدود ۱۰ میلی‌ثانیه بیشتر.
- **روتر، نه تک‌تک دستگاه‌ها.** کنسول و تلویزیون اپ VPN ندارند.

## امکانات

| | |
|---|---|
| AWG 3.1 داخل کرنل | `kmod-amneziawg` و ابزار `awg`، بیلد با SDK رسمی OpenWrt. فریم‌ور دست نمی‌خورد. |
| کل شبکه از VPN | policy routing. خود روتر همیشه در دسترس می‌ماند و قفل نمی‌شوی. |
| Split tunnel | همه‌ی رنج‌های IPv4 ایران (از RIPE) با روت `throw` مستقیم می‌روند. فقط یک lookup در کرنل است، بدون فایروال و conntrack. اثرش روی پینگ صفر اندازه گرفته شد. |
| رفع DNS | DNS روتر به 1.1.1.1 از داخل تونل. دامنه‌های فیلتر مثل توییتر و دیسکورد درست resolve می‌شوند. با خاموش‌شدن VPN خودکار مستقیم می‌شود. |
| پورت مبدأ ثابت | بعضی ISPها خروجی بین‌الملل را per-flow هش می‌کنند. `ListenPort` ثابت مسیر خوب را بعد از هر restart نگه می‌دارد. |
| `vpnctl` | روشن، خاموش، وضعیت از لپ‌تاپ با SSH. در مک یک منوی دابل‌کلیکی هم هست. |

## سازگاری

| روتر | OpenWrt | Target | پکیج |
|---|---|---|---|
| Google WiFi (Gale, AC-1304) | 23.05.4 | `ipq40xx/chromium` | **آماده**، هر روز در حال استفاده |
| هر روتر دیگر | 23.05.x و مشابه | هر target | با `build/build-packages.sh` بیلد کن، حدود ۱۰ دقیقه در داکر |

ماژول کرنل فقط روی **دقیقاً همان کرنلی** لود می‌شود که برایش بیلد شده. مشخصات روترت را با `cat /etc/openwrt_release` ببین. بعد از آپدیت فریم‌ور باید دوباره بیلد کنی.

## راه‌اندازی سریع

**۱. سرور:** یک سرور AmneziaWG 3.1، مثلاً اپ Amnezia و گزینه‌ی self-hosted روی یک VPS. راهنما: [docs/server-setup.md](docs/server-setup.md).

**۲. کانفیگ روتر:** در اپ یک کلاینت **جدید** بساز و با فرمت AmneziaWG خروجی `.conf` بگیر. خطوط `Address`، `DNS` و `MTU` را پاک کن. مقدار `Address` را نگه دار، پایین لازم است. الگو: [`router-files/awg1.conf.example`](router-files/awg1.conf.example).

**۳. پکیج‌ها:** برای Google WiFi با 23.05.4 کاری لازم نیست. برای روترهای دیگر:

</div>

```sh
./build/build-packages.sh 23.05.5 ramips mt7621     # <version> <target> <subtarget>
```

<div dir="rtl">

**۴. نصب:** از مک یا لینوکسی که به LAN روتر وصل است و با root به روتر SSH دارد:

</div>

```sh
ROUTER=root@192.168.1.1 TUNNEL_ADDR=10.8.1.2/32 ./install.sh ./awg1.conf
# روتر دیگر:  ... ./install.sh ./awg1.conf ./out/23.05.5-ramips-mt7621
# گزینه‌ها: SPLIT_TUNNEL=0 (همه از VPN)، SET_DNS=0 (DNS دست نخورد)، SSH_KEY=~/.ssh/key
```

<div dir="rtl">

**۵. کنترل:**

</div>

```sh
cp vpnctl.env.example vpnctl.env    # یک‌بار ROUTER و SSH_KEY را بنویس
./vpnctl status                     # هندشیک، ترافیک، تعداد روت‌های مستقیم، IP خروجی
./vpnctl off                        # کل خانه مستقیم
./vpnctl on
```

<div dir="rtl">

در مک روی `scripts/VPN.command` دابل‌کلیک کن تا منو با کلیدهای جهت‌نما باز شود.

## چطور کار می‌کند

</div>

```
دستگاه LAN ──► روتر (br-lan)
                 │  ip rule: iif br-lan → table 110
                 ▼
            table 110:  throw <رنج‌های ایران، شبکه‌های خصوصی، CGNAT>  ──► جدول main ──► WAN (مستقیم)
                        default dev awg1  ──► AmneziaWG 3.1 (UDP مبهم) ──► VPS ──► اینترنت
```

<div dir="rtl">

- `router-files/awg3-up` تونل را بالا می‌آورد، جدول ۱۱۰ را با یک `ip -batch` پر می‌کند (حدود ۱ ثانیه برای ۱۷۰۰ روت) و DNS را از تونل می‌برد. تنظیمات در `/etc/amneziawg/awg3.env`.
- رول `iif br-lan` است، **نه** `from 192.168.x.0/24`. دومی جواب‌های خود روتر به LAN را هم وارد تونل می‌کند و SSH را از دست می‌دهی.
- فقط ترافیک دستگاه‌ها تونل می‌شود. ترافیک خود روتر مستقیم می‌رود.

### Split tunnel

- لیست: `router-files/bypass-v4.txt`. به‌روزرسانی یا تغییر کشور: `COUNTRY=IR ./build/update-bypass-list.sh --deploy`
- افزوده‌های خودت: `/etc/amneziawg/bypass-extra.txt` روی روتر (هیچ‌وقت بازنویسی نمی‌شود)، بعد `vpnctl restart`.
- محدودیت: سایت ایرانی که پشت CDN خارجی است IP خارجی دارد و از VPN می‌رود. باز می‌شود، فقط مستقیم نیست.

### پورت مبدأ ثابت (ListenPort)

بعضی ISPها (روی آسیاتک دیده شد) ترافیک بین‌الملل را **per-flow** بین چند خروجی پخش می‌کنند و پورت مبدأ UDP جزو هش است. با پورت تصادفی پینگ تونل ۱۹۵ شد، با پورت‌های ۴۰۰۰۱ تا ۴۰۰۰۸ بین ۷۷ تا ۸۷. برای همین `ListenPort` در `awg1.conf` ثابت است. اگر پینگ تونل بالا رفت، پورت دیگری را زنده و بدون قطع تونل امتحان کن:

</div>

```sh
awg set awg1 listen-port 40011; sleep 2; ping -c 10 10.8.1.0     # IP تونل سرور (Amnezia: 10.8.1.0)
```

## عیب‌یابی

| علامت | راه‌حل |
|---|---|
| هندشیک ندارد | پارامترهای مبهم‌سازی باید **دقیقاً** با سرور یکی باشند. peer روی سرور هست؟ (`awg show`) پورت UDP روی VPS باز است؟ |
| پینگ هست ولی صفحه‌های سنگین باز نمی‌شوند | MTU: مقدار `MTU` در `awg3.env` را ۴۰ تا کم کن و `vpnctl restart`. عدد ۱۲۵۶ امن است. |
| توییتر و دیسکورد باز نمی‌شوند ولی تلگرام بله | DNS مسموم است. روی روتر `ip route get 1.1.1.1` باید `dev awg1` باشد. وای‌فای گوشی را یک‌بار خاموش و روشن کن. |
| opkg ماژول را قبول نمی‌کند یا «kernel mismatch» | پکیج برای کرنل دیگری است. با `build/build-packages.sh` دوباره بیلد کن. |
| از روتر قفل شدی | IPv6 محلی هنوز کار می‌کند: `ping6 ff02::1%en0` و بعد `ssh root@fe80::…%en0`. یا درست بعد از روشن‌کردن روتر SSH بزن. |

## هشدارها

- **آپدیت فریم‌ور یعنی بیلد دوباره.** ماژول به vermagic کرنل قفل است.
- روی روتری که پکیج سفارشی دارد `opkg upgrade` کورکورانه نزن.
- همه‌چیز با root روی روترت اجرا می‌شود. اول اسکریپت‌ها را بخوان. بدون هیچ ضمانتی.
